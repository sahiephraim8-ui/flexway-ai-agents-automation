# FlexWay Workspace

App client + admin pour FlexWay — agence web & automatisation IA (Côte d'Ivoire).

**Live:** https://96cf01b2ac464a148e.v2.appdeploy.ai/  
**Admin:** `/#/admin` | Clé : `FlexWay2024`  
**Stack:** React + Vite + TypeScript + AppDeploy

## Services
1. Création de site web (formulaire `/#/formulaire`)
2. Optimisation de site (`/#/optimisation`)
3. Workflows & Automatisation (`/#/workflows`)
4. Agent WhatsApp IA (`/#/whatsapp-ia`)

## Admin
- Fiches clients par service avec statuts (Brief → Design → Dev → Livraison)
- Planning 3 slots/mois
- Onglet Tarification — grille complète 4 services × 3 plans
- Lien de suivi token par client (`/#/suivi/:token`)

## Historique versions
- **v1** : formulaires + admin de base
- **v2** : suivi token, planning, scoring IA, brief copiable
- **v2.1** *(2026-05-20)* : onglet Tarification dans admin (PricingView.tsx)
